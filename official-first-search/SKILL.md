# Official First Search

## Prefer Official Sources

When the official source is known, read it directly or search within its site. Add third-party sources only when official material is not enough.

Community posts, repository issues, and package directories on official domains are not automatically official conclusions.

## Prioritize Version Relevance and Currency

For version-sensitive questions, prefer official documentation and release notes for the relevant version. Exclude historical archives and prerelease material that do not apply.

When third-party sources are needed, prefer content published after or close to the target version's release date and clearly applicable to that version. A recent publication date does not mean the content is up to date.

## Respect the Default Search Configuration

Do not explicitly set a `provider`. Prefer the current default search engine. If key official material cannot be found, use other available engines as needed for additional searches. Do not search with two engines in parallel by default.

## Do Not Stop at an Empty Dynamic Page

If an official page returns only navigation or an empty shell, first look for its public Markdown, raw files, or the data source the page actually loads. Do not immediately switch to third-party copies.
